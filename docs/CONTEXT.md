# Contesto tecnico — Fakeflix

Aggiornato: 2026-09-08

## Obiettivo
Demo responsive ispirata a una piattaforma streaming, costruita senza framework per esercitare JavaScript nativo, DOM, eventi e gestione dello stato.

## Stato
- Demo frontend funzionante e pubblicata.
- Nessun backend, autenticazione, pagamento o riproduzione video reale.
- Stato e rendering sono gestiti in JavaScript vanilla.

## Punto di ripresa
Nessun lavoro attivo obbligatorio. Eventuali interventi dovrebbero riguardare bug, accessibilità, performance o rifiniture, senza alterare lo scope educativo salvo decisione esplicita.

## Tema UI — 2026-10-02
Pulsante sole/luna accessibile nell’intestazione, tema coerente con i colori esistenti e scelta ricordata nel browser.
